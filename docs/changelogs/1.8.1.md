- 备份凭据迁移：OpenList Token 和 S3 访问凭据稳定保存到用户配置目录中的 `backup.local.yaml`；兼容 Windows 旧安装目录凭据迁移，避免升级或卸载后丢失配置。
- 发布安全检查：Windows 发布 staging 会主动排除 `backup.local.yaml`、本地备份文件和 S3 凭据，发布配置模板不包含实际敏感信息。
- OpenList 兼容性：连接测试和上传前改为校验远程目录，不再自动创建远程目录；兼容部分 WebDAV 服务对 `PROPFIND`、`HEAD` 等方法的限制。
- 备份稳定性：大文件打包增加读取进度；导出、导入和恢复操作增加并发等待超时，避免维护任务长期阻塞。
- 远程上传反馈：区分上传失败、元数据失败和部分成功；当 ZIP 已上传但元数据失败时保留 ZIP 并明确提示。
- 远程历史：增加元数据读取超时和并发限制；远程元数据不可用时，可根据备份文件名识别全量备份、单实例备份和多实例备份。
- 备份恢复：优化远程备份下载、恢复失败保护、备份实例筛选和排序流程。
- 交互反馈：统一备份成功、警告和错误提示，优化通知中心、Toast 和备份过程记录展示。
- 隐私展示：不再在备份页面展示本地备份目录完整路径。
- 日志与运行维护：日志页面默认显示 `INFO` 及以上级别，改善残留进程清理和异常退出后的状态处理。
