## 1.9.8 - 2026-11-24

- 更新：新增「更新通道」，默认只检测正式版；预览版按 GitHub Release 的 prerelease 标记识别，可在弹窗里切换。
- 更新：同一通道存在多个新版本时可在「版本」下拉里指定（最多列 2 个，且都高于当前版本）。
- 更新：检查更新阶段也能指定代理池节点或自定义代理，并记住上次选择，后台检查会沿用。
- 更新：侧边栏红点基于最近一次成功检查结果，直连被阻断导致的检查失败不再误清除提示，切通道后也不会串用其他通道的结果。
- 更新：退出安装改为静默安装（NSIS `/S`），完成后自动启动新版本；静默失败时自动退回可见安装向导。
- 修复：退出并安装时等待脚本无法启动（DETACHED_PROCESS 让 PowerShell 立即退出），安装包不会被拉起。
- 修复：安装等待脚本没起来时不再直接退出应用，改为明确报错并保留应用。
- 修复：预览通道的最新版本低于当前版本时不再允许下载，避免降级安装。
- 优化：更新弹窗精简为「当前版本 / 最新版本」一行，底部只保留关闭、下载并且安装、打开项目页。
