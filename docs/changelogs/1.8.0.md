- 备份渠道：支持本地、OpenList 和 S3（含兼容服务）三种备份位置，统一上传进度与结果反馈。
- 备份范围：支持全量备份和按实例选择性备份；备份历史支持本地、OpenList、S3 三个来源切换。
- 远程历史：支持扫描远程备份列表，下载远程备份包，并从 OpenList 或 S3 历史记录恢复。
- OpenList 定时备份：支持每日执行时间、最近执行状态和失败反馈；检测到实例仍在运行时跳过本次任务。
- 凭据保护：OpenList Token 和 S3 访问凭据保存到本地敏感配置，界面默认脱敏并支持按需显示，不写入普通 `config.yaml`。
- 恢复安全：备份包增加 manifest 文件数量、大小和 SHA-256 校验，导入时校验归档路径、条目类型和解压限制。
- 恢复兼容：导入 SQLite 时保留历史字段，按当前机器归一化实例和内核路径，并按稳定 `coreId` 映射外部内核。
- 代理连接栈：明确区分 `xray` + sing-box 组合栈与独立 `mihomo` 栈，完善实例启动、测速、健康检测、预热和代理下载的统一路由。
- 设置维护：新增系统设置重置，增加定时备份配置保护，并整理根目录辅助文件和开发启动入口。
