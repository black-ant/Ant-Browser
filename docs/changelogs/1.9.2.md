- 虚拟分组：完善健康判定、探测节流与故障切换选点，全组降级时明确拒绝启动，避免实例挂在不可用节点上。
- 插件加载重构：改为按实例通过启动参数加载未打包目录，不再写入 Chrome 的 `Secure Preferences`，修复原方式被 Chrome 判定无效后连带删除插件代码目录、表现为「装了但看不到」的问题。
- 插件数据隔离：每个实例的插件数据写入各自实例目录，移除某个实例的插件不会波及其他实例。
- 内置插件：随安装包分发，首次启动自动解压并登记为已启用，不默认安装到实例；需要在「插件包管理」勾选「默认安装」或按实例指定。
- 插件包管理：新增「打开实例」列出正在使用该插件的实例，可直接启动或停止；插件启停即时生效，失败自动回滚；修复内置插件绑定 ID 被格式过滤丢弃的问题。
- 数据修复（迁移 v30）：清理「已开启手动设置但没有任何插件」的实例配置，避免这些实例永久无法跟随默认安装。
- mieru：域名解析后按延迟优选 IP，复用探活缓存，启动失败自动回退下一个地址。
- 备份凭据：OpenList Token 和 S3 访问凭据稳定保存到用户配置目录中的 `backup.local.yaml`，兼容 Windows 旧安装目录凭据迁移，避免升级或卸载后丢失配置。
- 备份稳定性：大文件打包增加读取进度；导出、导入和恢复增加并发等待超时，避免维护任务长期阻塞；远程上传区分上传失败、元数据失败和部分成功，ZIP 已上传但元数据失败时保留文件并明确提示。
- 远程备份：增加元数据读取超时和并发限制，远程元数据不可用时按文件名识别全量备份、单实例备份和多实例备份；优化远程下载、恢复失败保护、备份实例筛选和排序流程。
- OpenList 兼容性：连接测试和上传前改为校验远程目录，不再自动创建远程目录，兼容部分 WebDAV 服务对 `PROPFIND`、`HEAD` 等方法的限制。
- 交互反馈：统一备份成功、警告和错误提示，优化通知中心、Toast 和备份过程记录展示；备份页面不再展示本地备份目录完整路径。
- 发布安全：Windows 发布 staging 主动排除 `backup.local.yaml`、本地备份文件和 S3 凭据，发布配置模板不包含实际敏感信息。
- 日志与运行维护：日志页面默认显示 `INFO` 及以上级别，改善残留进程清理和异常退出后的状态处理。
