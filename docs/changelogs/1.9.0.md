- 插件加载方式重构：改为按实例通过启动参数加载未打包目录，不再写入 Chrome 的 `Secure Preferences`。原方式会被 Chrome 启动时判定无效，连带删除插件代码目录，表现为「装了但看不到」。
- 插件数据隔离：每个实例的插件数据写入各自的实例目录，互不影响；移除某个实例的插件不会波及其他实例。
- 内置插件：随安装包分发，首次启动自动解压并登记为已启用，不默认安装到实例；需要在「插件包管理」勾选「默认安装」或按实例指定。
- 插件包管理新增「打开实例」：列出正在使用该插件的实例，可直接启动或停止。
- 插件启停即时生效：移除逐个实例扫描插件目录的开销，卡片状态改为即时反馈，失败自动回滚。
- 数据修复（迁移 v30）：清理「已开启手动设置但没有任何插件」的实例配置，避免这些实例永久无法跟随默认安装。
