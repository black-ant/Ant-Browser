## 🚀 如何使用

### 启动开发环境
```bash
bat\dev.bat
```

### 测试智能抓包
```
1. 启动浏览器实例
2. 进入「浏览器开发工具」
3. 等待 3 秒后点击「刷新实例」
4. 选择实例，点击「连接」
5. 按钮显示「连接中...」
6. 连接成功后访问 https://jsonplaceholder.typicode.com/posts
7. 点击快捷筛选 📋 JSON(100)
8. 点击请求查看树状结构 ✅
```
